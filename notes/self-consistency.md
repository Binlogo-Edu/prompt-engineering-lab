# Self-Consistency

## Status

Completed on 2026-04-07 after concept check.

## Core idea

Self-Consistency 是对 CoT 的增强。它不依赖单次生成的答案，而是让模型通过多条不同的推理路径生成多个答案，然后用**多数投票**选出最一致的结果。

## 背景：CoT 的局限

标准 CoT 基线通常采用**单次生成**；很多实现会直接用**贪婪解码（greedy decoding）**，每一步选概率最高的 token，于是只得到一条推理路径和一个答案。

问题：推理路径一旦走偏，最终答案就错了，没有纠错机制。

## Self-Consistency 的做法

1. 使用 few-shot CoT prompt
2. **多次采样**，让模型走出多条不同的推理路径
3. 提取每条路径的最终答案，并对这些答案进行**多数投票**
4. 票数最多的答案作为最终输出

关键词：**多路径 + 投票**

## 示例

问题：我6岁时姐姐是我年龄的一半，现在我70岁，姐姐多大？

- 不用 CoT 的输出：35（错误）
- 用 Self-Consistency 后三次输出：
  - Output 1：67 ✓
  - Output 2：67 ✓
  - Output 3：35 ✗

多数票 → 67，答案正确。

## 为什么有效

- 同一个问题可以通过不同的推理路径到达正确答案
- 错误的推理路径通常各不相同（错误是发散的）
- 正确的推理路径往往收敛到同一个答案
- 多数投票过滤掉了偶发的推理错误

## 适用场景

- 算术推理
- 常识推理
- 任何有明确正确答案、且可以通过多步推理得出的任务

## 局限性

- **Token 成本高**：需要多次生成，成本是单次 CoT 的数倍
- **需要确定性答案**：对于开放式生成任务（写作、翻译），"多数投票"没有意义
- **依赖基础推理能力**：如果模型本身连单条推理链都很不稳定，多采样通常也救不回来

## 与其他技术的关系

```
Zero-shot       ──→ 无示例，直接回答
Few-shot        ──→ 有示例，学格式
CoT             ──→ 示例含推理步骤，单次生成
Self-Consistency ──→ CoT × 多次采样 + 多数投票
```

## My summary

- Self-Consistency 用多条推理路径替代单条贪婪解码
- 它本质上是 CoT 的**采样与聚合策略**，不是一种完全独立的新推理范式
- 错误是发散的，正确答案是收敛的，投票机制利用了这一特性
- 显著提升 CoT 在推理任务上的准确率，代价是更高的 Token 消耗

## Review result

Self-test passed on 2026-04-07.

What I got right:

- CoT 单次生成一旦推理走偏就没有纠错机会，Self-Consistency 用多路径+投票解决这个问题
- 核心步骤：多次采样 → 多条推理路径 → 提取最终答案 → 多数投票
- 错误路径发散、正确路径收敛，投票天然倾向正确答案
- 开放式写作任务无效：没有客观正确答案，"文无第一"，投票机制无从发力
- 主要代价：Token 消耗成倍增长，被淘汰路径浪费算力，只适合对准确率要求高的确定性任务
- 它更准确地说是对 CoT 解码方式的改进，而不是说 "CoT 本身就等于贪婪解码"
